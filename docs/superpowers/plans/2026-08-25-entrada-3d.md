# Portada como entrada 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sustituir la portada estática actual ("Bienvenido al almanaque" en texto) por un entorno 3D navegable con una puerta como punto de acceso: al pasar el ratón/tocar la puerta saluda con ese mismo texto, y al hacer clic navega a una nueva ruta `/archivo` (placeholder por ahora).

**Architecture:** Escena Three.js renderizada con `@react-three/fiber` (`<Canvas>`) y compuesta con helpers de `@react-three/drei` (`OrbitControls`, `Stars`, `Text`, `Html`, `useCursor`). Toda la geometría es generada por código (primitivas), sin modelos 3D externos. La puerta es un `<group>` con mesh de marco+panel que gestiona hover (saludo flotante) y clic (navegación).

**Tech Stack:** React 18 + TypeScript + Vite (ya existente), + `three`, `@react-three/fiber`, `@react-three/drei` (nuevas dependencias), react-router-dom (ya existente).

**Spec:** `docs/superpowers/specs/2026-08-25-entrada-3d-design.md`

## Global Constraints

- El saludo de la puerta al hacer hover debe ser exactamente: **"Bienvenido al almanaque — entra"** (sustituye al `<h1>` estático que había antes en `Home.tsx`).
- Sin modelos 3D externos ni texturas descargadas — toda la geometría con primitivas de Three.js (`boxGeometry`, `planeGeometry`, etc.) y materiales emissive para el efecto neón.
- Controles de cámara: `OrbitControls` (arrastrar/orbitar), no movimiento en primera persona.
- Clic en la puerta navega a `/archivo` vía `useNavigate()` de `react-router-dom`.
- **`node`/`npm` SÍ están disponibles en este entorno** (a diferencia del plan anterior de scaffolding) — cada tarea se valida con `npm run build` real (`tsc && vite build`), no con comprobaciones estáticas de grep/JSON.
- Versiones exactas a usar (verificadas por compatibilidad de peer dependencies con React 18.3.1, ver más abajo): `three@^0.185.1`, `@react-three/fiber@^8.18.0`, `@react-three/drei@^9.122.0`, `@types/three@^0.185.4`. **No usar `@react-three/fiber@9` ni `@react-three/drei@10`** — esas versiones mayores requieren React 19 como peer dependency y romperían la instalación con este proyecto (React 18.3.1).

- [ ] **Step 1: Crear `src/pages/Home/Door.tsx`**

```tsx
import { useState } from 'react'
import { useNavigate } from 'react-router-dom'
import { Html, useCursor } from '@react-three/drei'

function Door() {
  const [hovered, setHovered] = useState(false)
  const navigate = useNavigate()
  useCursor(hovered)

  return (
    <group
      position={[0, 1.25, 0]}
      onPointerOver={() => setHovered(true)}
      onPointerOut={() => setHovered(false)}
      onClick={() => navigate('/archivo')}
    >
      <mesh position={[-0.9, 0, 0]}>
        <boxGeometry args={[0.2, 2.5, 0.2]} />
        <meshStandardMaterial color="#0ff0fc" emissive="#0ff0fc" emissiveIntensity={1.2} />
      </mesh>
      <mesh position={[0.9, 0, 0]}>
        <boxGeometry args={[0.2, 2.5, 0.2]} />
        <meshStandardMaterial color="#0ff0fc" emissive="#0ff0fc" emissiveIntensity={1.2} />
      </mesh>
      <mesh position={[0, 1.25, 0]}>
        <boxGeometry args={[2, 0.2, 0.2]} />
        <meshStandardMaterial color="#0ff0fc" emissive="#0ff0fc" emissiveIntensity={1.2} />
      </mesh>

      <mesh position={[0, 0, -0.05]}>
        <boxGeometry args={[1.6, 2.4, 0.1]} />
        <meshStandardMaterial color="#120024" emissive="#7b2ff7" emissiveIntensity={0.4} />
      </mesh>

      {hovered && (
        <Html position={[0, -1.4, 0]} center>
          <div
            style={{
              color: '#0ff0fc',
              fontFamily: 'system-ui, sans-serif',
              fontSize: '1rem',
              whiteSpace: 'nowrap',
              textShadow: '0 0 8px #0ff0fc',
              pointerEvents: 'none',
            }}
          >
            Bienvenido al almanaque — entra
          </div>
        </Html>
      )}
    </group>
  )
}

export default Door
```

- [ ] **Step 2: Crear `src/pages/Home/Scene.tsx`**

```tsx
import { Stars, OrbitControls, Text } from '@react-three/drei'
import Door from './Door'

function Scene() {
  return (
    <>
      <color attach="background" args={['#03010a']} />
      <ambientLight intensity={0.3} />
      <pointLight position={[0, 2, 3]} intensity={2} color="#0ff0fc" />
      <pointLight position={[0, 2, -2]} intensity={1} color="#7b2ff7" />

      <Stars radius={50} depth={50} count={3000} factor={4} saturation={0} fade speed={0.5} />

      <mesh rotation={[-Math.PI / 2, 0, 0]} position={[0, 0, 0]}>
        <planeGeometry args={[40, 40]} />
        <meshStandardMaterial color="#050311" roughness={0.9} />
      </mesh>

      <Text
        position={[0, 3, 0]}
        fontSize={0.4}
        color="#0ff0fc"
        anchorX="center"
        anchorY="middle"
      >
        ARCHIVO OASIS
      </Text>

      <Door />

      <OrbitControls
        target={[0, 1.25, 0]}
        minDistance={3}
        maxDistance={12}
        minPolarAngle={Math.PI / 6}
        maxPolarAngle={Math.PI / 2.1}
      />
    </>
  )
}

export default Scene
```
